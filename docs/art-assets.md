## 风格判断

全系列为**瑞士国际主义排版 / 抽象构成 / 信息图表**语言：粗线几何、网格、注记文字（EDGE / INDEGREE / MEMORY INDEX / landing site 之类的伪技术标签）、高对比荧光点缀色。**没有任何中世纪具象插画。**

结论：不适合做"王国题材"的叙事插画，但**非常适合做裁判引擎界面的视觉语言**——本游戏数字版的界面本体就是制度文书：结算表、契约登记、事件日志、谈话/资金/契约三张图。用档案感、公文感的抽象信息图风格呈现，比拟物中世纪风更贴合"系统裁判"的产品定位，也能全部复用现有素材。
